보안 Agent 「헤임달」

제로 트러스트 보안 Agent를 직접 설계하고 구현했습니다. 사용자·기기·세션 확인, 업무 앱 접근 판정, 보안 기록·XDR 경보, AI 연결 상태, 조치 상태, 설치 패키지 취약점 조회 화면을 만들어 ALEPH 판정 환경에서 13~22단계 코드 검토를 모두 통과했습니다. 이어진 총공세(판정 없는 개선 기간)에서는 내 PC를 실제로 읽어 직전 측정과 비교하는 기능을 더하고, 값을 Windows 기본 도구와 대조했습니다.

  • 10 / 1013~22단계 코드 검토 통과. 17단계는 일부 항목이 운영 정책에 따른 임시 통과
  • 6 / 6내 PC 실측 항목(CPU·메모리·디스크·네트워크·방화벽·Windows 기록)을 일반 권한으로 읽음
  • verified앱 서버를 거친 수업용 AI 연결 확인(2026-10-29, 모델 응답 1개)

내가 만든 부분

  • 학생 화면 코드 student/extension.mjs: 화면 함수 8개(13~20단계)
  • 상태 요약 카드와 이번 실행 추이, 기록·패키지 요약 카드
  • 「내 PC 측정 추이 비교」: 제공 조회 값을 다시 구현하지 않고 쌓아 직전 측정과 비교
  • 「다시 조회」·대기 표시·조회 실패 항목과 다음 할 일 안내, 키보드 조작
  • 앱 이름 「헤임달」과 화면 배치·색(꾸밈 파일), 실행 안내 한 장과 기록 문서

제공된 부분과 실제 연결 조건

  • 앱 서버·공통 화면·실행 도구·「내 PC 상태」 조회는 과정에서 제공된 시작 틀(0.2.21)입니다
  • 판정·탐지는 접근 제어 서버(SDP)가 하며, 실제 연결에는 서버·연결 어댑터·서버 담당자가 발급하는 개인 인증서가 모두 필요합니다
  • 이번 과정에서는 인증서 발급 대상이 아니어서 기본 실행은 「SDP 미연결」로 표시되고, 기록·판정 화면은 예제 데이터로 확인했습니다

총공세: 판정 없는 7일 개선

  1. 1일차 상태 요약 카드 네 개와 이번 실행 추이, 핵심 기능 점검표
  2. 2일차 「내 PC 측정 추이 비교」: CPU·메모리·디스크를 잰 시각·단위와 함께, 작업 관리자·파일 탐색기와 대조
  3. 3일차 네트워크 구성·방화벽 설정·Windows 기록 건수(읽기만, 침해 판정 아님), SDP 미연결을 PC 조회와 분리
  4. 4일차 학생 카드 먼저 배치, 「다시 조회」와 대기 표시, 조회 실패 항목과 다음 할 일, 키보드 조작
  5. 5일차 처음 보는 사람용 실행 안내 한 장. 헷갈리기 쉬운 곳(폴더 위치·앱 이름)을 보완하고, 친구가 안내만 보고 실행해 문제 없음
  6. 6일차 마무리 커밋을 GitHub에 올리고 40자리 커밋 번호 확인
  7. 7일차 시연 순서, 한계와 근거 정리. 이후 web.dev·W3C WAI 기준으로 대비·초점 표시를 다듬음

아직 안 되거나 확인하지 못한 것

  • 실제 로그인·기기·세션·보안 기록·업무 앱 판정·조치: 접근 제어 서버 미연결이라 예제 데이터로만 화면 확인
  • AI 사건 설명: AI 연결은 확인했지만 설명할 실제 보안 기록이 없어 미확인
  • 실제 OSV 취약점 결과: 조회 대상 프로젝트가 설정되지 않아 미확인(「조회 안 됨」은 0건·안전으로 표시하지 않음)
  • 권한 없음·오래된 값·취소 표시: 모의 응답으로만 확인
  • macOS·Linux 실행, 설치형 포장: 하지 않음
