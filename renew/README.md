# renew — 사이트의 숫자와 문단 후보를 다시 만드는 장치

새 기록을 넣고 한 번 돌리면 사이트 `index.html`의 **숫자 칸**과 **승인한 문단**이 바뀝니다.
Python 3.9 이상 표준 라이브러리만 씁니다. AI를 부르지 않으므로 같은 입력이면 항상 같은 결과가 나옵니다.

## 돌리는 방법 (세 단계)

1. **기록 넣기** — `input/ritual/`에 리추얼 기록 내보내기(JSON)를 넣습니다. 출석·제출 숫자도 넣으려면
   `input/attendance.csv`(또는 화면 요약 `input/attendance-summary.json`)와 `input/submissions.csv`를 만듭니다(형식은 같은 폴더의 `*.example.csv`).
2. **돌리기** — 이 폴더에서 `python3 renew.py --site ../index.html`
   (사이트 없이 결과만 보려면 `python3 renew.py`)
3. **승인하기** — `out/candidates.md`에서 쓰고 싶은 후보의 id를 `approved.json`에 옮기고(문장을 고쳐 써도 됨) 2단계를 한 번 더 돌립니다. 승인 목록에 있는 문장만 사이트에 들어갑니다.

## 입력

| 파일 | 내용 | 없으면 |
|---|---|---|
| `input/ritual/*.json` | `{"days":[{"date","open":[…],"close":[…]}]}` 형식. 여러 파일이면 날짜로 합치고 같은 날짜는 파일 이름 순으로 뒤의 것을 씁니다. | 멈춤 |
| `input/attendance.csv` | `date,status` — status는 출석/지각/조퇴/결석/공가/확정전 (「내 출석 기록」 날짜별) | 요약 파일을 씀 |
| `input/attendance-summary.json` | 출석 화면 요약 `{기준일, 훈련일, 재적일, 출석, 결석, 확정전}` | 출석 칸 생략 |
| `input/submissions.csv` | `no,title,submitted_on,status` (「내 제출 현황」) | 제출 칸 생략 |
| `config.json` | 과정 시작일·전체 주 수, 능력별 키워드, 후보를 뽑을 기록 칸 | — |
| `approved.json` | 사이트에 넣기로 승인한 후보 `{id, ability, text}` 목록 | — |

## 출력 (`out/`)

- `stats.json` — 숫자 칸의 원본. 출처(리추얼 기록 / 내 출석 기록 / 내 제출 현황)별로 나뉩니다.
- `candidates.md`, `candidates.json` — 능력(자기조절력·대인관계력·자기동기력)별 문단 후보. 후보마다 날짜와 근거(기록 날짜·칸 이름)가 붙습니다.
- `site-block.html` — 사이트에 들어가는 HTML 조각: 첫 화면 ‘한눈에 보기’ 카드, 숫자 칸, 13주 리추얼 달력(평일 하루가 한 칸), 승인한 문단.
- 실행할 때마다 네 파일의 SHA-256을 출력합니다. 두 번 돌려 값이 같으면 재현된 것입니다.

`--site`를 주면 `index.html`의 `<!-- renew:glance -->`, `<!-- renew:stats -->`, `<!-- renew:paragraphs -->` 표시 사이만 바꿉니다. 이야기 본문은 손으로 쓴 그대로 둡니다.

## 세는 방법

- 기록일: 날짜 수. 마감기록일: `close`가 있는 날짜 수.
- 실천/일부/못 했다: 마감 칸 `강점 행동:` 문구의 완전일치 개수.
- 기록 주: `course_start`부터 7일 단위로 센 주 가운데 기록이 있는 주.
- 최장 연속: ‘못 했다’ 없이 이어진 마감 기록 수. 회복: ‘못 했다’ 다음 처음 ‘실천했다’까지의 달력 일수.
- 출석률: 출석 화면과 같은 식 (출석 + 공가) ÷ 재적일. 확정 전인 날도 재적일에 들어갑니다.
- 제출: 행 수, 제출일이 있는 행, status가 `최종 확인 완료`인 행.
- 달력: `course_start`부터 13주 × 평일. 마감 ‘강점 행동’이 실천(밝은 칸)·일부(어두운 칸)·못 했다(✕ 테두리)로, 시작 기록만 있는 날은 테두리, 기록 없는 날·휴일은 회색, 개강 전과 남은 날은 빈 칸.
- 감사 기록: 마감 칸의 `내가 나눈 감사`, `감사일기` 줄 수.
- 후보: 기록 칸에 능력별 키워드가 많이 걸린 순(같으면 날짜 순)으로 능력마다 6개. `(이름 가림)`이 들어간 문장은 뽑지 않습니다.

## 공개 주의

`input/`과 `out/candidates.*`에는 기록 원문이 들어 있어 공개 저장소에는 올리지 않습니다(`.gitignore`). 비밀값은 쓰지 않습니다.
